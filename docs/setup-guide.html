ssg-agent 설치 안내 (Windows)

처음 한 번만 하면 되는 준비 과정입니다. 단계 제목을 눌러 펼치세요.

1프로그램 2개 설치Python, Git

Python

  1. 브라우저에서 python.org/downloads 에 들어갑니다.
  2. 노란색 Download Python 3.xx 버튼을 눌러 받습니다.
  3. 받은 파일을 실행합니다.
설치 창 맨 아래 ☑ Add python.exe to PATH 칸을 반드시 체크한 뒤 Install Now를 누르세요.

Git

  1. git-scm.com/download/win 에 들어갑니다.
  2. Click here to download를 눌러 받습니다.
  3. 아무것도 바꾸지 말고 Next만 계속 누르다가 마지막에 Install을 누릅니다.
2명령 프롬프트 열기검은 창에 명령어 붙여넣는 법
  1. 키보드의 ⊞ 윈도우 키를 누릅니다.
  2. cmd 라고 입력합니다.
  3. 명령 프롬프트를 클릭합니다.

이 안내의 명령어는 오른쪽 복사 버튼을 누르고, 검은 창에서 마우스 오른쪽 클릭으로 붙여넣은 뒤 Enter를 누르면 됩니다.

설치 확인

python --version
git --version

두 명령 모두 숫자(버전)가 나오면 성공입니다.

숫자 대신 Microsoft Store가 열리거나 “인식되지 않습니다”가 나오면, 창을 닫고 다시 열어 보세요. 그래도 안 되면 Python 설치 때 PATH 체크를 빠뜨린 것이니 다시 설치하세요.
3프로젝트 받고 준비하기한 줄씩 차례로 실행

앞 명령이 끝나서 다시 >가 보이면 다음 줄로 넘어가세요.

① ‘문서’ 폴더로 이동

cd %USERPROFILE%\Documents

② GitHub에서 프로젝트 받기

처음이면 GitHub 로그인 창이 뜰 수 있습니다. 로그인하면 됩니다.

git clone -b claude/brave-albattani-uyuue1 https://github.com/ssg-supabase/ssg-agent.git

③ 프로젝트 폴더로 들어가기

cd ssg-agent

④ 전용 파이썬 공간(가상환경) 만들기

python -m venv .venv

⑤ 가상환경 켜기

켜지면 줄 맨 앞에 (.venv)가 붙습니다.

.venv\Scripts\activate

⑥ 필요한 라이브러리 설치

1~2분 걸리고 글자가 많이 지나갑니다. 정상입니다.

pip install -r requirements.txt
4API 키 붙여넣기메모장으로 .env 파일 편집

① 키 양식 파일을 복사해 .env 만들기

copy .env.example .env

② 메모장으로 열기

notepad .env

③ 키 바꿔 넣기

메모장에 이렇게 보입니다.

ANTHROPIC_API_KEY=여기에_Anthropic_키
GEMINI_API_KEY=여기에_Gemini_키
OPENAI_API_KEY=여기에_OpenAI_키

여기에_..._키 부분만 지우고 실제 키를 붙여넣으면 이런 모양이 됩니다.

ANTHROPIC_API_KEY=sk-ant-api03-abcd1234...
GEMINI_API_KEY=AIzaSyAbcd1234...
OPENAI_API_KEY=sk-proj-abcd1234...
= 앞뒤에 띄어쓰기나 따옴표를 넣지 마세요. #으로 시작하는 설명 줄은 그대로 둬도 됩니다.

④ 저장

Ctrl + S로 저장하고 메모장을 닫습니다. 이 파일은 내 컴퓨터에만 있고 GitHub에는 올라가지 않습니다.

5실행하고 확인하기자주 나는 에러 포함
python hello_claude.py

Claude의 자기소개 한 문장과 [사용 토큰]이 나오면 성공입니다.

에러에 보이는 말원인과 해결
authentication_errorAnthropic 키가 틀렸거나 띄어쓰기가 들어갔습니다. 4단계를 다시 확인하세요.
credit balance is too lowAnthropic 콘솔에서 결제 수단이나 크레딧을 등록해야 합니다.
No module named ...가상환경이 꺼져 있습니다. 줄 앞에 (.venv)가 있는지 보고, 없으면 3단계 ⑤를 다시 실행하세요.

다른 에러가 나면 빨간 글씨 마지막 몇 줄을 복사해서 Claude에게 보내주세요.
